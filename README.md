#  Granja El Roble | Oracle SQL Database

**Diseño y gestión de bases de datos relacionales con Oracle SQL.**

Base de datos orientada a la organización de información de una granja, incluyendo animales, corrales, encargados, alimentos y veterinarios.

##  Características principales

-  **Modelado relacional:** organización de entidades y relaciones.
-  **Integridad de datos:** claves primarias, foráneas y restricciones.
-  **Gestión de registros:** inserción, actualización y eliminación de datos.
-  **Consultas SQL:** filtros, ordenamiento y recuperación de información.
-  **Análisis de datos:** funciones de agregación y agrupación de resultados.

##  Tecnologías y herramientas

Oracle SQL: lenguaje utilizado para crear, modificar y consultar la base de datos.

Oracle SQL Developer: entorno de trabajo para escribir, ejecutar y comprobar sentencias SQL.

Visual Studio Code: editor de código utilizado para organizar y modificar los archivos del proyecto.

Git: sistema de control de versiones para registrar cambios en el código.

GitHub: plataforma para alojar el repositorio y compartir el proyecto.

##  SQL aplicado

| Categoría | Comandos |
|---|---|
| Definición de datos | `CREATE TABLE`, `ALTER TABLE` |
| Manipulación de datos | `INSERT`, `UPDATE`, `DELETE` |
| Consultas | `SELECT`, `WHERE`, `ORDER BY` |
| Agregación | `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` |
| Agrupación | `GROUP BY`, `HAVING` |

##  Ejecución

1. Clona o descarga este repositorio.
2. Abre `sql/granja_el_roble.sql` en Oracle SQL Developer.
3. Configura la conexión a Oracle Database.
4. Ejecuta el script y comprueba los resultados.

##  Propósito

Aplicar principios de diseño relacional y SQL para estructurar información, mantener la consistencia de los datos y facilitar su consulta.
